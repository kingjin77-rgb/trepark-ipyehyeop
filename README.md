# trepark-ipyehyeop

## PICKPLAY - 가상 포인트 승부예측 게임

`predict/index.html`에 위치한 정적 웹 데모입니다. 실제 현금 충전/환전 없이 가상 포인트(시작 10,000P)로 축구·야구·e스포츠 경기 결과를 예측하고, 친구들과 리더보드 순위를 겨루는 오락용 게임입니다.

- 경기 데이터는 데모용 샘플이며, 상단 "결과 시뮬레이션" 버튼으로 즉시 결과를 확인할 수 있습니다.
- 모든 상태는 브라우저 `localStorage`에 저장되는 프런트엔드 전용 데모입니다(서버/DB 없음).
- 실제 서비스로 확장하려면 실시간 경기 결과 API와 회원 계정/서버 기반 리더보드 연동이 필요합니다.

`predict/admin.html`은 같은 브라우저의 데이터를 관리하는 관리자 페이지입니다: 경기 등록/수정/삭제와 결과 확정(자동 정산), 플레이어·봇 포인트 지급/차감, 베팅 취소/삭제, 시작 포인트·베팅 한도 설정, 전체 데이터 초기화를 지원합니다.
